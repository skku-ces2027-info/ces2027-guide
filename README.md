# CES 2027 연수단 안내

성균관대 '2027 미래기술 탐방연수' 연수단이 CES 2027(2027-01-06~08) 세션·키노트·입장 규칙·기한을 날짜·트랙·건물로 찾고, 한국어 요약과 원문 링크를 보는 정적 사이트다. 데스크톱과 휴대폰에서 모두 쓴다.
학교가 확정한 일정이 아니라 CES 공식 페이지와 보도에서 모은 공개 정보다.

화면 문구(제목·탭·필터 이름)는 영어이고, 항목 내용(요약·입장 규칙·업데이트 기록)은 CSV에 적은 한국어 그대로 나온다.

## 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` · `style.css` · `app.js` | 화면. 빌드 도구 없음. |
| `data/items.csv` | 항목 한 줄 = 하나. 사이트가 이 파일을 읽어 필터와 목록을 만든다 |
| `data/updates.csv` | `날짜,내용`. 머리띠의 '업데이트' 기록 창에 쓰인다 |
| `maps/strip.svg` | 첫 화면을 채우는 수채 지도. 건물마다 이름표와 항목 수가 붙고, 이름표를 누르면 그 건물 항목만 남는다(`app.js`의 `PIN`). 좌표는 건물 단위이고 CES 2026 기준이다. 지도 데이터 © OpenStreetMap 기여자(ODbL) |
| `maps/city.svg` | 라스베이거스 일대 전체의 간선도로 지도. 시작 장면에서만 쓴다. 화면이 이 지도에서 시작해 행사장 쪽으로 확대해 들어간 뒤 `strip.svg`로 넘어간다(`app.js`의 `intro`). 한 브라우저 세션에서 한 번만 길게 나오고, 휠·키·터치로 바로 건너뛴다 |
| `maps/strip_detail.svg` | 같은 지도를 번짐 없이 선명하게 그린 것. 행을 펼치면 그 건물 주변을 보여 주고, 누르면 전체 지도가 크게 열린다(`app.js`의 `openMap`) |
| `maps/lvcc.svg` · `venetian_1f.svg` · `venetian_2f.svg` | 홀·층 배치도. 전체 지도 창의 두 번째 탭으로 나온다(`app.js`의 `plan`) |
| `tools/refine_maps.py` | 가이드북 지도의 공개용 사본(원본)을 사이트용으로 다시 칠한다. 아래 '지도 다시 만들기' 참고 |
| `tools/city_map.py` | OpenStreetMap에서 받은 도로 데이터로 `maps/city.svg`를 그린다. 받는 질의와 실행법은 파일 머리말에 있다 |
| `og.png` | 링크를 공유할 때 보이는 미리보기 그림(1200×630) |

## 데이터 고치는 법

1. `data/items.csv`를 엑셀·Numbers·편집기로 연다. UTF-8(BOM 있어도 됨)로 저장한다.
2. 바뀐 항목은 `변경일`을 오늘로 바꾼다. 최근 갱신일부터 7일 안의 항목에 '새로' 표시가 붙는다.
3. `data/updates.csv` 맨 위(어디든 됨)에 오늘 날짜로 한두 줄을 더한다. 가장 늦은 날짜가 '갱신일'이 된다.
4. 로컬에서 확인한 뒤 commit · push 하면 GitHub Pages에 몇 분 안에 반영된다.

로컬 확인:

```bash
python3 -m http.server 8427 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:8427 을 연다(파일을 직접 열면 CSV를 못 읽는다).

### 화면에 나오는 영어 표기

CSV의 `분류`·`우리트랙`·`패스`·`상태`·`근거` 값은 한국어 그대로 두고, 화면에서만 영어로 바꿔 보여 준다(`app.js` 맨 위의 `EN`).
CSV에 새 값을 쓰면 `EN`에 영어 표기를 한 줄 더한다. 더하지 않으면 CSV에 적은 값이 그대로 나온다.

### 지도 다시 만들기

`maps/strip.svg`와 `maps/strip_detail.svg`는 원본 지도(가이드북 생성기가 내보낸 공개용 사본)를 `tools/refine_maps.py`로 다시 칠한 것이다.
박혀 있던 글자와 지시선을 빼고, 주변 건물을 옅은 물감 면으로 바꾸고, 행사장 건물이 모두 온전히 들어오게 범위를 잡는다. 한 번 실행하면 두 장이 함께 나온다.

```bash
python3 tools/refine_maps.py <원본 strip.svg> --palette clear
```

`maps/city.svg`는 `strip.svg`와 같은 투영을 8분의 1로 줄여 그리므로, 화면에서 8배 키우면 두 지도가 정확히 겹친다. 범위(`VIEW`)를 바꾸면 `tools/city_map.py`도 다시 돌린다.

색을 바꾸려면 `tools/refine_maps.py`의 `PALETTES`와 `style.css` 맨 위의 색 토큰(`--paper`, `--lvcc`, `--ven`, `--cspace`, `--font`)을 함께 고친다.

### `items.csv` 컬럼

| 컬럼 | 값 |
|---|---|
| `id` | 겹치지 않는 짧은 이름(`s6-005`, `k-01`, `r-03` …) |
| `분류` | 세션 · 키노트 · 무대·행사 · 입장 규칙 · 기한 · 부스 정보 |
| `제목` | 한국어 제목. 세션은 한 줄 요약을 쓴다 |
| `원제목` | 세션의 CES 원래 제목(영문). 세션이 아니면 비운다 |
| `날짜` · `시작` · `끝` | `2027-01-06` · `09:00` · `09:40`. 날짜가 1/6~8이 아니면 '출국 전 기한', 비우면 '날짜 상관없음'으로 묶인다 |
| `건물` · `방` | `LVCC North` · `N258 (2층)` |
| `우리트랙` | AI · 모빌리티·로보틱스 · 헬스·바이오 · 에너지·지속가능 · 공통 · 그 밖. 여러 개는 `;`로 잇는다 |
| `CES트랙` | CES 세션표의 트랙 이름 |
| `패스` | Standard · 유료 트랙 · 별도 티켓 (비워도 됨) |
| `상태` | 공개 · 작년 기준 예상 · 미정 |
| `요약` · `할일` | 한국어 설명. 세션의 `할일`을 비우면 패스에 맞는 기본 안내가 붙는다 |
| `원문링크` | `https://`로 시작하는 주소만 링크가 된다 |
| `근거` | 공식-직접확인 · 공식-요약 · 2차 · 추정 |
| `확인일` · `변경일` | `2026-11-04` |

## 공개 원칙

- 개인 이름·연락처, 조 명단, 학교 내부 결정은 넣지 않는다.
- 원문은 짧게 인용하지 않고 한국어로 새로 요약한다. 세션 원제목만 그대로 둔다.
- 기업 부스는 관심 있는 학생의 개별 방문 정보로만 둔다(연수단 단체 방문 요청 없음).
- 왼쪽 위에는 'SKKU 2027 미래기술 탐방연수'(공식 행사명 그대로), 제목은 'SKKU at CES 2027'로 적는다. 공식 영문 행사명이 정해지면 `index.html`의 `.brand`에 넣는다.
- 맨 아래에 만든 사람(이름·소속), 저작권, 지도·글꼴 출처, CTA·학교와 무관한 비공식 안내라는 점을 밝힌다.
